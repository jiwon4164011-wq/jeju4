06. 핵심 기능

AI가 4가지를 자동으로 추천합니다

제목과 설명을 입력하면 키워드를 분석해 즉시 결과를 보여줍니다.

STEP 1
위험 유형
‘계단·미끄러움·전선·비상구’ 같은 키워드를 유형별 사전과 대조해 가장 점수가 높은 유형을 고릅니다.
STEP 2
위험도 1~4단계
감전·추락·유리 등 위험 단어는 점수를 올리고, ‘약간·경미’ 같은 단어는 내립니다. 사람이 많은 구역이면 가중치를 더합니다.
STEP 3
담당 부서
유형에 따라 시설관리부·전기안전담당·환경위생부·체육부·학생안전부로 자동 배정합니다.
STEP 4
내용 요약 + 신뢰도
‘어디서 무엇이 어떻게 위험한지’ 한 문장으로 요약하고, 분석 신뢰도를 %로 함께 보여줍니다.
// 입력 "3층 계단 난간이 흔들려서 추락할 것 같아요" // AI 분석 결과 { type: "바닥/계단", severity: 4, // 긴급 dept: "시설관리부", summary: "본관 3층 계단에서 난간이 흔들려 …", confidence: 0.86 }
낮음 불편하지만 즉시 위험하지 않음
보통 방치하면 사고 가능성 있음
높음 부상 위험, 빠른 조치 필요
긴급 중대 사고 우려, 즉시 조치

💡 최종 판단은 담당 선생님이 확인하고 수정할 수 있습니다. AI는 판단을 대신하는 것이 아니라 빠른 분류를 돕는 역할입니다.

11. 개인정보

이름도, 학번도 받지 않습니다

🙈 완전 익명 접수

신고자는 관리자 화면에서도 항상 ‘학생’으로만 표시됩니다.

🏷️ 학번 대신 닉네임

학번을 입력받지 않습니다. 내가 쓴 신고를 찾기 위한 식별자는 자동 생성되며 화면에 나오지 않습니다.

📷 사진 촬영 안내

친구 얼굴이 나오지 않게 찍어달라는 안내를 신고 화면에 표시합니다.

설계 원칙

  • 신고에 부담이 없어야 위험이 빨리 드러납니다
  • 필요한 정보만 받습니다 — 위치 · 유형 · 사진 · 설명
  • 데이터는 학교가 쓰는 브라우저와 구글 시트에만 남습니다

※ 관리자 암호는 브라우저에 저장되는 간단한 잠금입니다. 실제 운영에서는 서버 인증이 필요합니다.
